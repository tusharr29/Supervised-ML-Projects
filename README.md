# Supervised Machine Learning Projects

A small static website showcasing six supervised machine learning projects. The homepage lists each project; selecting a project opens a dedicated detail page with its overview, key concepts, technology stack, GitHub repository, and live application link (where available).

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `supervised-ml-projects`.
2. Upload all files and folders from this directory, keeping the structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After GitHub Pages publishes the site, use the generated URL in LinkedIn's Projects section.

## Files
- `index.html` — project collection homepage
- `projects/` — individual project detail pages
- `assets/style.css` — shared responsive styling
