Heart Disease Prediction

An interactive machine learning application that predicts the likelihood of heart disease from patient health information.

Project overview

This project explores a supervised classification workflow for heart disease prediction. It compares multiple classification algorithms, applies statistical feature selection with the Chi-square test, evaluates models using cross-validation, and tunes an SVM classifier with GridSearchCV and RandomizedSearchCV. The selected model is deployed through Streamlit.

Key concepts and workflow

  • Exploratory Data Analysis
  • Data preprocessing and encoding
  • Feature scaling with StandardScaler
  • Chi-square feature selection
  • Logistic Regression, KNN, Naive Bayes, Decision Tree and SVM comparison
  • Cross-validation
  • GridSearchCV and RandomizedSearchCV
  • Model evaluation and Streamlit deployment
Educational demonstration only. This project is not a substitute for professional medical advice or diagnosis.
