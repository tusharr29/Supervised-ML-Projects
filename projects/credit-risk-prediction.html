Credit Risk Prediction

A financial risk modelling project focused on identifying applicants with a higher likelihood of credit default.

Project overview

This project explores credit-risk data and develops a supervised classification workflow for an imbalanced target. It includes combining source datasets, exploratory data analysis, understanding class imbalance and preparing features for model development. The goal is to distinguish lower-risk and higher-risk cases while evaluating performance beyond accuracy.

Key concepts and workflow

  • Dataset merging and data validation
  • Exploratory Data Analysis
  • Class imbalance analysis
  • Data preprocessing and feature preparation
  • Supervised classification
  • Model comparison
  • Precision, recall and F1-score considerations
