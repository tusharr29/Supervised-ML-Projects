Insurance Cost Prediction

An end-to-end regression project that estimates medical insurance charges from demographic and lifestyle information.

Project overview

This project predicts individual medical insurance charges using features such as age, gender, BMI, number of children and smoking habits. The workflow includes exploratory analysis, data cleaning, categorical encoding, feature engineering, statistical analysis and evaluation of a Linear Regression model. The trained model is available through an interactive Streamlit application.

Key concepts and workflow

  • Exploratory Data Analysis
  • Data cleaning and duplicate handling
  • Categorical encoding and feature engineering
  • Pearson correlation analysis
  • Chi-square statistical testing
  • Linear Regression
  • R-squared, Adjusted R-squared, MAE and RMSE
  • Streamlit deployment
Main algorithm
Linear Regression
