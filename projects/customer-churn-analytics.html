Customer Churn Prediction

A classification application that predicts customer churn and helps explore patterns associated with customer retention.

Project overview

This project uses customer subscription data to predict whether a customer is likely to leave a service. The workflow includes preprocessing categorical and numerical features, scaling, training a KNN classifier and evaluating model performance. The deployed Streamlit app makes the model accessible through an interactive interface.

Key concepts and workflow

  • Exploratory Data Analysis
  • Data cleaning and preprocessing
  • Categorical encoding
  • Feature scaling with StandardScaler
  • K-Nearest Neighbors classification
  • Model evaluation using ROC-AUC
  • Model serialization with Joblib
  • Streamlit deployment
Main algorithm
K-Nearest Neighbors (KNN)
