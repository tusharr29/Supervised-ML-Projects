Stroke Prediction

A binary classification project that estimates stroke risk from patient-related features.

Project overview

This project applies a Logistic Regression model to a healthcare dataset to classify stroke outcomes. It demonstrates the machine learning workflow from data preparation and exploratory analysis through model training, evaluation and deployment as an interactive Streamlit application. The model is intended for educational demonstration, not medical diagnosis.

Key concepts and workflow

  • Exploratory Data Analysis
  • Data cleaning and preprocessing
  • Feature preparation
  • Logistic Regression
  • Binary classification
  • Classification model evaluation
  • Model deployment with Streamlit
Educational demonstration only. This project is not a substitute for professional medical advice or diagnosis.
