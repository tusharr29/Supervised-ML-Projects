Student Performance Prediction

A machine learning project that predicts students' exam scores using academic, personal and environmental factors.

Project overview

This end-to-end project uses student-related information to estimate exam performance. It demonstrates a regression workflow using Python, Pandas and Scikit-learn, with an interactive Streamlit interface for generating predictions.

Key concepts and workflow

  • Exploratory Data Analysis
  • Data preprocessing
  • Feature analysis
  • Hypothesis testing and statistical analysis
  • Linear Regression
  • Regression model evaluation
  • Interactive prediction interface
  • Streamlit deployment

Linear Regression
